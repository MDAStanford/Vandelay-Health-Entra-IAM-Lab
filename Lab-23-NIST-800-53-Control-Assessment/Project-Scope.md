# Project Scope — SEC-2026-1023

## Business Objective
Vandelay Health's executive leadership has requested a 30-day internal security assessment to determine whether the company's identity and access management (IAM) controls are implemented, operating effectively, and supported by sufficient evidence.

The assessment will identify confirmed security deficiencies, evaluate associated risks, and recommend corrective actions. The results will help leadership understand the company's identity security posture and prepare for potential future federal contracting requirements.

## Systems in Scope
- Microsoft Active Directory (AD): on-premises account management, group membership, account termination, and privileged access.
- Microsoft Entra ID: cloud identity management, authentication controls, access reviews, privileged access, and hybrid synchronization.
- Okta: identity lifecycle and access controls supporting the El Segundo warehouse, where applicable evidence is available.

## Assessment Activities
- Review relevant security policies and existing assessment findings.
- Collect and examine technical evidence from system owners.
- Evaluate selected controls against NIST SP 800-53 Revision 5 using NIST SP 800-53A assessment methods.
- Interview stakeholders and conduct technical validation where feasible.
- Document control test results, evidence limitations, and confirmed deficiencies.
- Develop a remediation plan for confirmed deficiencies.

## Out of Scope
- Network penetration testing.
- Application source-code security testing.
- Physical security assessments.
- Medical device safety and clinical performance testing.
- A comprehensive assessment of every NIST SP 800-53 control.
- Formal FedRAMP authorization or certification.

## Schedule and Deliverables
**Planned assessment period:** 30 calendar days.
**Day 14:** Preliminary findings briefing to the CISO.
**Day 30:** Final executive presentation and delivery of:
- Security Assessment Report (SAR).
- Plan of Action and Milestones (POA&M).
- Executive summary and recommended corrective actions.

These are planned scenario milestones. Assessment start and milestone calendar dates remain to be confirmed; completed delivery is not claimed.

## Stakeholders
The assessment will require coordination with IAM Administration, IT Infrastructure, Security Engineering, HR Operations, Compliance/GRC, and Warehouse IT.

Evidence requests will be tracked, with department owners expected to respond within five business days. Material delays will be escalated to the CISO.

Named resource assignments, interview schedules, and technical-validation appointments remain to be confirmed.

## Assessment Limitations
Findings must be supported by available documentation, technical evidence, or reproducible testing. Missing evidence will be documented as an assessment limitation and will not automatically be treated as proof of a failed security control.

This is a simulated internal assessment conducted for the Vandelay Health IAM portfolio.
